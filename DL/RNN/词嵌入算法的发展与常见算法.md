# 词嵌入算法的发展与常见算法

## 1. 什么是词嵌入？

计算机不能直接理解"苹果""香蕉""汽车"这样的自然语言，因此需要将词转换成数值向量。

例如：

``` text
苹果 → [0.21, -0.73, 0.18, ...]
香蕉 → [0.25, -0.69, 0.22, ...]
汽车 → [-0.81, 0.15, 0.64, ...]
```

理想情况下，语义相近的词，其向量也应该比较接近：

``` text
苹果 ↔ 香蕉     距离较近
苹果 ↔ 汽车     距离较远
```

词嵌入的发展，本质上就是在解决：

> **如何把词转换成能够被神经网络计算，同时又尽可能保留语义信息的向量？**

整体发展路线可以概括为：

``` text
离散表示
  ↓
统计表示
  ↓
静态稠密词向量
  ↓
上下文动态表示
  ↓
Transformer 大模型中的 Token Embedding
```

------------------------------------------------------------------------

## 2. 第一阶段：One-Hot ------ 只有身份，没有语义

最简单的词表示方法是 One-Hot Encoding。

假设词表为：

``` text
我
喜欢
苹果
香蕉
```

可以表示为：

``` text
我     → [1, 0, 0, 0]
喜欢   → [0, 1, 0, 0]
苹果   → [0, 0, 1, 0]
香蕉   → [0, 0, 0, 1]
```

数学上：

$$
x_i \in \mathbb{R}^{|V|}
$$

其中 $|V|$ 表示词表大小。

### One-Hot 的问题

不同词之间彼此正交：

$$
x_i^T x_j = 0 \quad (i \ne j)
$$

因此从 One-Hot 向量本身来看：

``` text
苹果 和 香蕉
```

与：

``` text
苹果 和 汽车
```

没有任何语义距离上的区别。

此外，如果词表包含 100 万个词，每个词就需要 100 万维向量，非常稀疏。

所以 One-Hot 只能表示：

> **"这个词是谁？"**

却无法表示：

> **"这个词是什么意思？"**

------------------------------------------------------------------------

## 3. 第二阶段：基于统计的词表示

后来人们提出一个重要思想：

> **一个词的含义，可以通过它周围经常出现什么词来判断。**

这就是分布假设（Distributional Hypothesis）。

例如：

``` text
我喜欢吃苹果
我喜欢吃香蕉
苹果是一种水果
香蕉是一种水果
```

"苹果"和"香蕉"经常出现在类似的上下文中，因此可以认为它们的语义比较接近。

### 常见统计方法

-   共现矩阵（Co-occurrence Matrix）
-   TF-IDF
-   LSA / LSI
-   SVD 降维

例如建立共现向量：

``` text
苹果 → [100, 80, 5, 1]
香蕉 → [90, 85, 1, 0]
汽车 → [1, 0, 2, 120]
```

可以明显发现：

$$
v_{\text{苹果}} \approx v_{\text{香蕉}}
$$

这时候已经能够表达一定程度的语义相似性。

但共现矩阵通常非常巨大且稀疏，因此需要进一步：

``` text
高维稀疏向量
      ↓
低维稠密向量
```

这为现代 Embedding 奠定了基础。

------------------------------------------------------------------------

## 4. 第三阶段：神经网络词嵌入

神经网络语言模型开始直接为每个词学习一个低维稠密向量。

假设词表大小为：

$$
|V| = 100000
$$

以前使用 One-Hot：

$$
x \in \mathbb{R}^{100000}
$$

现在可以将每个词表示成：

$$
x \in \mathbb{R}^{300}
$$

整个词表可以使用一个 Embedding Matrix：

$$
E \in \mathbb{R}^{|V| \times d}
$$

例如：

$$
E \in \mathbb{R}^{100000 \times 300}
$$

矩阵中的每一行，就是一个词对应的 Embedding。

这也是 PyTorch：

``` python
nn.Embedding(
    num_embeddings=100000,
    embedding_dim=300
)
```

背后的基本思想。

------------------------------------------------------------------------

## 5. Word2Vec ------ 词嵌入真正流行

2013 年，Mikolov 等人提出 Word2Vec。

Word2Vec 主要包含两种模型：

``` text
Word2Vec
├── CBOW
└── Skip-Gram
```

### 5.1 CBOW

CBOW 的核心思想是：

> **根据上下文预测中心词。**

例如：

``` text
我 喜欢 吃 [苹果] 和 香蕉
```

使用周围的词：

``` text
我、喜欢、吃、和、香蕉
```

预测中心词：

``` text
苹果
```

即：

$$
上下文 \rightarrow 中心词
$$

------------------------------------------------------------------------

### 5.2 Skip-Gram

Skip-Gram 与 CBOW 相反：

> **根据中心词预测周围的词。**

例如输入：

``` text
苹果
```

预测：

``` text
吃
水果
甜
香蕉
```

即：

$$
中心词 \rightarrow 上下文
$$

在训练预测任务的过程中，模型会不断调整 Embedding Matrix。

最终可能学习出：

``` text
苹果 → [0.21, -0.13, 0.72, ...]
香蕉 → [0.24, -0.11, 0.69, ...]
```

于是：

$$
v_{\text{苹果}} \approx v_{\text{香蕉}}
$$

Word2Vec 最重要的思想是：

> **词向量不是人为规定出来的，而是在完成预测任务的过程中通过反向传播学习出来的。**

------------------------------------------------------------------------

## 6. GloVe ------ 全局统计 + 词向量

2014 年出现 GloVe（Global Vectors）。

Word2Vec 更偏向利用局部上下文进行预测，而 GloVe 更强调：

> **利用整个语料库的全局词共现统计。**

可以粗略理解为：

``` text
GloVe
=
共现矩阵思想
+
低维稠密词向量
```

例如：

``` text
ice   与 solid 经常一起出现
steam 与 gas   经常一起出现
```

GloVe 会利用整个语料库中的共现概率关系学习词向量。

Word2Vec 和 GloVe 是传统静态词嵌入时代最经典的两类方法。

------------------------------------------------------------------------

## 7. FastText ------ 从词深入到子词

Word2Vec 存在一个明显问题：

``` text
play
playing
played
player
```

这些词基本被当成完全独立的词处理。

FastText 引入了 Subword（子词）思想。

例如：

``` text
playing
```

可以进一步拆成字符 n-gram：

``` text
pla
lay
ayi
yin
ing
...
```

因此一个词的表示可以由词本身和若干子词共同组成：

$$
v_{\text{playing}}
=
v_{\text{playing}}
+
v_{\text{pla}}
+
v_{\text{lay}}
+\cdots
$$

这样：

``` text
playing
played
player
```

就可以共享一部分信息。

FastText 对以下情况尤其有帮助：

-   生僻词
-   拼写变化
-   词形变化
-   未登录词（OOV）

------------------------------------------------------------------------

## 8. 静态词嵌入的问题：一词多义

Word2Vec、GloVe、FastText 都存在一个根本问题：

> **同一个词只有一个固定向量。**

例如英文单词：

``` text
bank
```

在：

``` text
I deposited money in the bank.
```

表示"银行"。

而在：

``` text
He sat on the river bank.
```

表示"河岸"。

传统词嵌入中：

$$
Embedding(bank)=固定向量
$$

无法根据上下文改变。

因此 Word2Vec、GloVe 等通常被称为：

> **Static Embedding（静态词嵌入）**

------------------------------------------------------------------------

## 9. ELMo ------ 上下文词嵌入

ELMo 引入了一个重要思想：

> **同一个词，在不同上下文中应该拥有不同的向量。**

例如：

``` text
I deposited money in the bank.
```

和：

``` text
He sat on the river bank.
```

其中 `bank` 的向量可以不同：

$$
v_{\text{bank}}^{(1)}
\ne
v_{\text{bank}}^{(2)}
$$

ELMo 使用双向 LSTM 根据上下文动态生成词表示。

这类表示被称为：

> **Contextual Embedding（上下文嵌入）**

------------------------------------------------------------------------

## 10. Transformer / BERT

Transformer 出现后，词表示进入了新的阶段。

以 BERT 为例，不再简单地认为：

``` text
一个词 → 一个固定语义向量
```

而是：

``` text
Token
  ↓
初始 Embedding
  ↓
Transformer
  ↓
结合上下文
  ↓
Contextual Representation
```

例如：

``` text
苹果发布了新款手机。
我今天吃了一个苹果。
```

虽然都有"苹果"，但经过 Transformer 后：

$$
h_{\text{苹果，公司}}
\ne
h_{\text{苹果，水果}}
$$

因为 Self-Attention 会结合句子中其他 Token 的信息重新计算表示。

------------------------------------------------------------------------

## 11. 现代大模型：Token Embedding

到了 GPT、Llama 等现代大语言模型中，更准确的说法通常是：

> **Token Embedding**

因为现代模型通常不会简单地按照完整的"词"进行切分，而是先通过 Tokenizer
将文本转换成 Token。

整体过程：

``` text
文本
 ↓
Tokenizer
 ↓
Token ID
 ↓
Embedding
 ↓
Transformer × N
 ↓
上下文表示
```

假设：

``` python
nn.Embedding(
    num_embeddings=50000,
    embedding_dim=4096
)
```

对应：

$$
E \in \mathbb{R}^{50000 \times 4096}
$$

如果：

``` text
某 Token → token_id = 1024
```

那么：

$$
E[1024]
$$

就是该 Token 对应的初始向量。

但需要特别注意：

> **nn.Embedding 得到的只是初始 Token
> Embedding，并不是最终包含完整上下文语义的表示。**

真正的过程是：

$$
Embedding(Token)
\rightarrow Transformer_1
\rightarrow Transformer_2
\rightarrow \cdots
\rightarrow Transformer_N
$$

经过多层 Transformer 后得到的隐藏状态，才大量融入上下文语义。

------------------------------------------------------------------------

## 12. 词嵌入的发展路线

``` text
One-Hot
  │
  │ 只有词的身份
  ↓
共现矩阵 / TF-IDF
  │
  │ 利用统计关系
  ↓
LSA / SVD
  │
  │ 高维稀疏 → 低维稠密
  ↓
神经网络语言模型
  │
  │ Embedding Matrix
  ↓
Word2Vec（2013）
  ├── CBOW
  └── Skip-Gram
  │
  ↓
GloVe（2014）
  │
  │ 全局共现统计
  ↓
FastText（2016）
  │
  │ Subword
  ↓
ELMo（2018）
  │
  │ 上下文动态词向量
  ↓
Transformer / BERT（2018）
  │
  │ Self-Attention 上下文表示
  ↓
GPT / Llama 等大语言模型
  │
  ↓
Token Embedding
+
多层 Transformer Contextual Representation
```

------------------------------------------------------------------------

## 13. 常见词嵌入算法总结

  类型               代表方法           核心特点
  ------------------ ------------------ ------------------------------------------
  离散表示           One-Hot            简单，但没有语义
  统计表示           共现矩阵、TF-IDF   根据词频和共现关系表示文本
  降维表示           LSA / SVD          高维稀疏向量转为低维稠密向量
  静态词嵌入         Word2Vec           CBOW / Skip-Gram，通过预测任务学习词向量
  静态词嵌入         GloVe              利用全局共现统计
  子词嵌入           FastText           使用字符 n-gram，能够利用词内部结构
  上下文嵌入         ELMo               根据上下文动态生成词向量
  Transformer 表示   BERT               Self-Attention + 双向上下文表示
  大模型表示         GPT、Llama 等      Token Embedding + 多层 Transformer

------------------------------------------------------------------------

## 14. 学习时建议重点掌握的路线

如果是为了学习深度学习和大语言模型，建议重点掌握：

``` text
One-Hot
   ↓
Word2Vec
   ↓
GloVe / FastText
   ↓
ELMo
   ↓
BERT
   ↓
GPT / Llama
```

其中最值得深入理解的是 **Word2Vec**。

因为 Word2Vec 可以帮助理解一个非常关键的问题：

> **Embedding 到底是怎样通过训练和反向传播学习出来的？**

例如 PyTorch：

``` python
embed = nn.Embedding(
    num_embeddings=len(word2idx),
    embedding_dim=5
)
```

本质上创建了一个可训练的 Embedding Matrix：

$$
E \in \mathbb{R}^{|V| \times 5}
$$

接下来通过 CBOW、Skip-Gram
或其他训练目标，利用损失函数和反向传播不断更新矩阵中的参数，最终让具有相似语义或相似上下文的
Token 得到相近的向量表示。
