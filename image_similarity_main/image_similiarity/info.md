# 模块简介
该模块将原图像作为训练集的输入和目标输出，通过自编码器完成图像重建。
自编码器由编码器+解码器构成，通过编码器处理之后，图像特征被提取为高维向量。这些向量可以通过解码器重建为图像。
我们将原始数据集的所有图片经过编码器处理，生成嵌入向量，然后存入向量数据库（如Chroma）。
用户输入图像时，首先通过编码器提取出高维向量，然后在上文构建的向量数据库中检索相似向量，根据向量和索引的对应关系得到相似图像，返回给用户。

## 4. 完整的维度变化过程

### 4.1 编码器（Encoder）

输入图像：(batch_size, 3, 64, 64)

    输入 RGB 图像
    (3, 64, 64)
         │
         ▼
    Conv1 + ReLU + MaxPool
    (16, 32, 32)
         │
         ▼
    Conv2 + ReLU + MaxPool
    (32, 16, 16)
         │
         ▼
    Conv3 + ReLU + MaxPool
    (64, 8, 8)
         │
         ▼
    Conv4 + ReLU + MaxPool
    (128, 4, 4)
         │
         ▼
    Conv5 + ReLU + MaxPool
    (256, 2, 2)
         │
         ▼
    Conv6 + ReLU + MaxPool
    (512, 1, 1)
         │
         ▼
    squeeze(-1).squeeze(-1)
         │
         ▼
    512维特征向量

### 4.2 解码器（Decoder）

输入特征：(batch_size, 512)

    512维特征向量
         │
         ▼
    unsqueeze(-1).unsqueeze(-1)
    (512, 1, 1)
         │
         ▼
    ConvTranspose1 + ReLU
    (256, 2, 2)
         │
         ▼
    ConvTranspose2 + ReLU
    (128, 4, 4)
         │
         ▼
    ConvTranspose3 + ReLU
    (64, 8, 8)
         │
         ▼
    ConvTranspose4 + ReLU
    (32, 16, 16)
         │
         ▼
    ConvTranspose5 + ReLU
    (16, 32, 32)
         │
         ▼
    ConvTranspose6 + Sigmoid
    (3, 64, 64)
         │
         ▼
    重建 RGB 图像

### 4.3 总结

编码器：
- 卷积层：逐步增加通道数，提取更丰富的特征。
- 池化层：每次将特征图的高和宽缩小为原来的一半。
- squeeze：去除大小为1的空间维度，得到512维特征向量。

解码器：
- unsqueeze：将512维特征向量恢复为4维张量。
- 转置卷积：每次将特征图的高和宽扩大2倍，同时减少通道数。
- Sigmoid：将输出像素值限制在[0,1]范围内。

完整维度变化：

Encoder:
(3,64,64) → (16,32,32) → (32,16,16)
→ (64,8,8) → (128,4,4) → (256,2,2)
→ (512,1,1) → (512)

Decoder:
(512) → (512,1,1) → (256,2,2)
→ (128,4,4) → (64,8,8) → (32,16,16)
→ (16,32,32) → (3,64,64)

注：上述维度均省略 batch_size。

#### 为什么卷积神经网络要在减小图像空间尺寸的同时增加通道数，而解码器又要反过来减少通道数、增大空间尺寸？

**卷积编码器通过减少空间分辨率、增加特征通道，把图像从像素表示转换为抽象特征表示；转置卷积解码器则利用这些特征，逐步生成具有空间结构的图像。**

#### 为什么需要这么繁杂的转换？直接压缩不行吗？
这是最关键的地方。
假设你的输入图像：

$$
3\times64\times64=12288
$$

一共12288个数值。
你最终想压缩为512个数值。
一种简单方法是直接使用全连接层：
```python
nn.Flatten()
nn.Linear(3 * 64 * 64, 512)
```

确实可以实现：

$$
12288\rightarrow512
$$

但是这种方法有明显缺点：全连接层没有利用图像天然的二维局部结构，而且参数量较大。

仅这一层就需要：

$$
12288\times512+512=6,291,968
$$

个可训练参数。
而卷积网络通过局部连接、权重共享和分层特征提取，可以更有针对性地学习图像结构。
例如，一条边缘不论出现在图像左上角还是右下角，同一组卷积核都可以尝试检测它。
因此，CNN 的多层转换并不只是为了压缩数据，而是为了在压缩过程中学习有用的特征表示。

最后总结：
- 编码器：空间尺寸逐渐减小，通道数通常逐渐增加，目的是提取并压缩图像特征。
- 解码器：空间尺寸逐渐增大，通道数通常逐渐减少，目的是将抽象特征转换成具体的图像。
- 多层转换的价值：不是单纯改变张量形状，而是让网络在每一层学习不同层次的特征。
