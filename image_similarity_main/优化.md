# 一、分类模型中损失函数的优化：从 MSELoss 到 TripletMarginLoss

## 1. 关于分类模块中损失函数的优化

在之前的模型中，我们首先定义了一个编码器（Encoder）和解码器（Decoder）。

输入图片经过 Encoder 的卷积和下采样操作，被压缩为低维特征表示；随后通过 Decoder 的上采样操作，将特征还原为与原始图片相同尺寸的输出，最后使用均方误差损失函数（MSELoss）计算重建图片与原始图片之间的差异，并通过反向传播优化模型参数。

整个过程如下：

```text
原始图片
    │
    ▼
Encoder（编码器）
    │
    │ 卷积 + 下采样
    ▼
低维特征向量
    │
    ▼
Decoder（解码器）
    │
    │ 上采样 + 转置卷积
    ▼
重建图片
    │
    ▼
MSELoss（与原始图片比较）
    │
    ▼
反向传播，更新模型参数
```

这种方式本质上属于**自编码器（Autoencoder）的重建训练**。

### 1.1 MSELoss 的原理

均方误差损失函数（Mean Squared Error Loss）的计算公式为：

$$
L_{\mathrm{MSE}} = \frac{1}{N}\sum_{i=1}^{N}(x_i-\hat{x}_i)^2
$$

其中：

- $x_i$：原始图片的第 $i$ 个像素值。
- $\hat{x}_i$：重建图片的第 $i$ 个像素值。
- $N$：图片中参与计算的元素总数。

MSELoss 通过逐元素比较原始图片与重建图片之间的差异，使模型尽可能保留输入图片的信息。

但是，**图像重建与图像分类的优化目标并不完全一致**。

图像重建关注的是能否还原原始图片，而图像分类更关注提取出的特征是否具有类别区分能力。

例如，两张属于同一类别的猫的图片，可能由于背景、光照、拍摄角度等因素，导致像素差异较大，但它们在语义上仍然属于同一类别。

因此，如果我们的主要任务是图像分类或相似度检索，仅使用 MSELoss 训练 Encoder，未必能够获得具有良好类别区分能力的特征。

需要强调的是，MSELoss 本身并没有问题，只是它的优化目标不一定适合分类任务。

### 1.2 分类模型的优化目标

为了改善这一问题，我们希望模型学习到的特征满足以下两个条件：

1. **类内紧凑性（Intra-class Compactness）**：属于同一类别的图片，在特征空间中的距离尽可能小。
2. **类间分离性（Inter-class Separability）**：属于不同类别的图片，在特征空间中的距离尽可能大，至少满足一定的间隔要求。

这里需要注意，我们比较的不是原始图片的像素距离，而是图片经过 Encoder 提取之后的**特征向量距离**。

例如：

```text
图片 A（猫） ──► Encoder ──► 特征向量 A
图片 B（猫） ──► Encoder ──► 特征向量 B
图片 C（狗） ──► Encoder ──► 特征向量 C
```

我们的目标是：

```text
distance(A, B) 尽可能小

distance(A, C) 相对更大
```

为了实现这一目标，我们引入一个新的概念：

**对比学习（Contrastive Learning）与度量学习（Metric Learning）中的距离约束损失。**

## 2. 三元组损失（Triplet Margin Loss）

三元组损失（Triplet Margin Loss）是一种经典的度量学习损失函数。

它通过比较三个样本之间的特征距离，优化模型的特征提取能力。

### 2.1 三元组的组成

每个三元组由三个样本组成：

| 名称 | 含义 | 示例 |
|---|---|---|
| Anchor（A） | 锚点样本，作为比较基准 | 一张猫的图片 |
| Positive（P） | 正样本，与 Anchor 属于同一类别 | 另一张猫的图片 |
| Negative（N） | 负样本，与 Anchor 属于不同类别 | 一张狗的图片 |

我们的目标是：

- 缩小 Anchor 与 Positive 之间的距离。
- 增大 Anchor 与 Negative 之间的距离。
- 保证负样本距离至少比正样本距离大一个指定间隔（Margin）。

可以理解为：

```text
          特征空间

    Anchor（猫）
       ●
       │
       │ 距离较小
       │
       ● Positive（猫）


                         ● Negative（狗）

       <---- 距离较大 ---->
```

### 2.2 数学公式

Triplet Margin Loss 的计算公式为：

$$
L_{\mathrm{triplet}} =
\max\left(0,d(A,P)-d(A,N)+m\right)
$$

其中：

- $A$：Anchor 的特征向量。
- $P$：Positive 的特征向量。
- $N$：Negative 的特征向量。
- $d(A,P)$：锚点与正样本之间的距离。
- $d(A,N)$：锚点与负样本之间的距离。
- $m$：间隔参数（Margin），通常为正数。

通常可以采用欧氏距离（Euclidean Distance）：

$$
d(x,y)=\sqrt{\sum_{i=1}^{D}(x_i-y_i)^2}
$$

其中 $D$ 表示特征向量的维度。

### 2.3 为什么需要 Margin？

假设：

$$
d(A,P)=0.8
$$

$$
d(A,N)=1.2
$$

设置：

$$
m=1.0
$$

代入损失函数：

$$
L=\max(0,0.8-1.2+1.0)
$$

得到：

$$
L=0.6
$$

虽然负样本距离已经大于正样本距离，但是两者的差距还不够大，因此模型仍然需要优化。

如果经过训练：

$$
d(A,P)=0.5
$$

$$
d(A,N)=1.8
$$

那么：

$$
L=\max(0,0.5-1.8+1.0)=0
$$

说明当前三元组已经满足要求。

因此，Triplet Margin Loss 实际上要求：

$$
\boxed{d(A,N)\geq d(A,P)+m}
$$

当满足这个条件时，当前三元组的损失为 0，不再产生进一步拉近或拉远的梯度。

需要注意，Triplet Loss 并不是让不同类别之间的距离无限增大，而是要求它们之间满足一定的相对距离约束。

### 2.4 MarginRankingLoss（边际排序损失）

`MarginRankingLoss` 是一种用于比较两个输入相对大小的损失函数，其核心思想是：**让模型学习两个输入之间的排序关系，并要求它们满足一定的间隔（Margin）。**

计算公式为：

$$
L = \max(0, -y(x_1-x_2)+m)
$$

其中：

- $x_1$、$x_2$：需要比较的两个数值，通常是模型输出的分数或距离。
- $y$：排序标签，取值为 `1` 或 `-1`。
  - `y=1`：希望 $x_1$ 比 $x_2$ 至少大 $m$。
  - `y=-1`：希望 $x_1$ 比 $x_2$ 至少小 $m$。
- $m$：间隔参数（Margin）。

#### PyTorch 实现

```python
import torch
import torch.nn as nn

criterion = nn.MarginRankingLoss(margin=1.0)

# 假设两个输入是距离
positive_distance = torch.tensor([0.5, 0.8])
negative_distance = torch.tensor([1.8, 1.2])

# 希望正样本距离小于负样本距离
target = torch.tensor([-1.0, -1.0])

loss = criterion(
    positive_distance,
    negative_distance,
    target
)

print(loss.item())  # 0.3
```

#### 与 TripletMarginLoss 的关系

实际上，`TripletMarginLoss` 可以理解为 `MarginRankingLoss` 在三元组距离比较场景中的一种具体应用。

假设：

$$
x_1=d(A,P),\quad x_2=d(A,N),\quad y=-1
$$

代入公式：

$$
L=\max(0,d(A,P)-d(A,N)+m)
$$

这与 `TripletMarginLoss` 的数学形式一致。

**两者的主要区别：**

- `TripletMarginLoss`：直接输入三个特征向量（Anchor、Positive、Negative），内部计算距离和损失。
- `MarginRankingLoss`：输入两个已经计算好的分数或距离，通过排序约束计算损失，使用场景更加灵活。

因此，`MarginRankingLoss` 不仅可以用于图像相似度学习，还可以用于推荐系统、搜索排序等任务。

## 3. PyTorch 中的 TripletMarginLoss

PyTorch 已经提供了 `nn.TripletMarginLoss()`，可以直接使用。

### 3.1 基本使用

```python
import torch
import torch.nn as nn

# 定义三元组损失函数
criterion = nn.TripletMarginLoss(
    margin=1.0,
    p=2,
    reduction="mean"
)

# 假设每个样本由128维特征向量表示
# batch_size = 32
anchor = torch.randn(32, 128)
positive = torch.randn(32, 128)
negative = torch.randn(32, 128)

# 计算三元组损失
loss = criterion(anchor, positive, negative)

print(loss.item())
```

这里使用随机向量只是为了演示 API 的调用方式。

实际训练时，三个特征向量应该由同一个 Encoder 提取，并且正负样本需要根据类别标签正确构建。

# 二、去噪模型中噪声引入优化

## 1. 原有噪声引入方式

在之前的图像去噪模型中，我们采用高斯噪声的方式对输入图片进行扰动，代码如下：

```python
# 向输入图像添加随机噪声
noisy_imgs = tensor_image + torch.randn_like(tensor_image) * NOISE_FACTOR

# 将像素值限制在 [0, 1] 范围内
noisy_imgs = torch.clamp(noisy_imgs, 0.0, 1.0)
```

其中：

- `tensor_image`：原始图片张量，形状为 `(C, H, W)` 或 `(N, C, H, W)`。
- `torch.randn_like()`：生成与输入张量形状相同的标准正态分布随机噪声。
- `NOISE_FACTOR`：控制噪声强度。
- `torch.clamp()`：将像素值限制在 `[0, 1]` 范围内。

这种方式实际上添加的是**高斯噪声（Gaussian Noise）**，而不是任意分布的随机噪声。

其数学表达式为：

$$
I_{\mathrm{noisy}} = \mathrm{clip}(I + \epsilon, 0, 1)
$$

其中：

$$
\epsilon \sim \mathcal{N}(0,\sigma^2)
$$

$\sigma$ 对应代码中的 `NOISE_FACTOR`。

由于 RGB 图片具有三个颜色通道，而 `torch.randn_like()` 会对每个通道独立生成随机噪声，因此可能出现大量彩色噪点。

例如，同一个像素位置的 R、G、B 通道可能分别受到不同程度的扰动，从而产生彩色斑点。

虽然高斯噪声能够模拟传感器噪声等随机扰动，但如果希望模拟图像中随机出现的黑白噪点，可以考虑引入**椒盐噪声（Salt-and-Pepper Noise）**。

---

## 2. 椒盐噪声（Salt-and-Pepper Noise）

椒盐噪声是一种典型的脉冲噪声（Impulse Noise），表现为图像中随机出现的黑色或白色像素。

- **椒噪声（Pepper Noise）**：将部分像素值设置为 `0`，表现为黑色。
- **盐噪声（Salt Noise）**：将部分像素值设置为 `1`，表现为白色。

与高斯噪声不同，椒盐噪声不会对所有像素添加连续随机扰动，而是随机选取部分像素，直接将其替换为黑色或白色。

### 2.1 数学原理

假设原始图片为 $I$，添加椒盐噪声后的图片为 $I'$：

$$
I'(x,y)=
\begin{cases}
0, & r < p/2 \\
1, & p/2 \leq r < p \\
I(x,y), & r \geq p
\end{cases}
$$

其中：

- $r$：服从均匀分布 $U(0,1)$ 的随机数。
- $p$：噪声概率，控制被污染像素的比例。
- $I(x,y)$：原始像素值。
- $I'(x,y)$：添加噪声后的像素值。

例如，当 `noise_prob=0.1` 时：

- 约 5% 的像素被设置为黑色。
- 约 5% 的像素被设置为白色。
- 约 90% 的像素保持不变。

注意，这些比例是概率意义上的期望值，实际每张图片的比例可能略有不同。

---

## 3. PyTorch 实现椒盐噪声

可以定义一个独立的函数，为输入图片添加椒盐噪声。

```python
import torch


def add_salt_pepper_noise(
    image: torch.Tensor,
    noise_prob: float = 0.1,
) -> torch.Tensor:
    """
    向图片添加椒盐噪声。

    Args:
        image: 输入图片张量，形状为(C,H,W)或(N,C,H,W)，
               像素值范围为[0,1]。
        noise_prob: 噪声概率，取值范围为[0,1]。

    Returns:
        torch.Tensor: 添加椒盐噪声后的图片。
    """
    if not 0.0 <= noise_prob <= 1.0:
        raise ValueError("noise_prob必须在[0,1]范围内")

    noisy_image = image.clone()

    # 每个像素位置生成一个随机数
    # RGB三个通道共享同一个噪声位置
    random_shape = (*image.shape[:-3], 1, *image.shape[-2:])
    random_values = torch.rand(
        random_shape,
        device=image.device
    )

    # 椒噪声：将部分像素设置为黑色
    pepper_mask = random_values < noise_prob / 2

    # 盐噪声：将部分像素设置为白色
    salt_mask = (
        (random_values >= noise_prob / 2)
        & (random_values < noise_prob)
    )

    noisy_image = torch.where(
        pepper_mask, 0.0, noisy_image
    )

    noisy_image = torch.where(
        salt_mask, 1.0, noisy_image
    )

    return noisy_image
```

### 3.1 使用方式

原来的代码：

```python
noisy_imgs = tensor_image + torch.randn_like(tensor_image) * NOISE_FACTOR
noisy_imgs = torch.clamp(noisy_imgs, 0.0, 1.0)
```

现在可以替换为：

```python
NOISE_PROB = 0.1

noisy_imgs = add_salt_pepper_noise(
    tensor_image,
    noise_prob=NOISE_PROB
)
```

这里特别注意：

**对于 RGB 图片，应该让三个颜色通道共享相同的椒盐噪声位置。**

如果对 R、G、B 三个通道分别随机生成噪声，就可能再次出现彩色噪点。

使用共享的噪声掩码，可以保证被选中的像素三个通道同时变为 `0` 或 `1`，从而产生真正的黑白噪点。

## 4. 高斯噪声与椒盐噪声的区别

| 对比项 | 高斯噪声 | 椒盐噪声 |
|---|---|---|
| 噪声类型 | 连续随机扰动 | 脉冲噪声 |
| 像素变化 | 在原始像素基础上增加随机值 | 将部分像素直接替换为0或1 |
| 视觉效果 | 颗粒状噪声，RGB通道独立扰动时可能出现彩色噪点 | 随机黑白噪点 |
| 控制参数 | `noise_factor` | `noise_prob` |
| 适用场景 | 模拟传感器等随机噪声 | 模拟脉冲干扰、像素损坏等情况 |

两种噪声没有绝对的优劣之分。

高斯噪声更适合模拟连续的随机信号扰动，而椒盐噪声更适合模拟部分像素受到严重污染的情况。

## 5. 进一步优化：混合噪声训练

为了让去噪模型适应不同类型的噪声，可以在训练过程中随机选择高斯噪声或椒盐噪声。

```python
import random
import torch


def add_random_noise(
    image: torch.Tensor,
    gaussian_factor: float = 0.1,
    salt_pepper_prob: float = 0.1,
) -> torch.Tensor:
    """
    随机为图片添加高斯噪声或椒盐噪声。
    """

    if random.random() < 0.5:
        # 高斯噪声
        noisy_image = image + torch.randn_like(image) * gaussian_factor
        noisy_image = torch.clamp(noisy_image, 0.0, 1.0)

    else:
        # 椒盐噪声
        noisy_image = add_salt_pepper_noise(
            image,
            noise_prob=salt_pepper_prob
        )

    return noisy_image
```

训练时：

```python
# 原始图片
clean_imgs = tensor_image

# 随机添加噪声
noisy_imgs = add_random_noise(clean_imgs)

# 输入去噪模型
outputs = model(noisy_imgs)

# 与原始干净图片计算损失
loss = criterion(outputs, clean_imgs)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

通过这种方式，模型可以在训练过程中接触不同类型的噪声，有助于提高对多种噪声分布的适应能力。

需要注意，训练噪声种类增加并不一定能提高所有测试场景下的效果，仍然需要通过验证集评估。

---

## 6. 总结

原有模型使用 `torch.randn_like()` 添加高斯噪声，由于 RGB 三个颜色通道独立受到随机扰动，可能产生大量彩色噪点。

引入椒盐噪声后，可以通过随机选择像素并将其设置为黑色或白色，模拟图像中局部像素受到严重污染的情况。

两种噪声的核心区别在于：

- **高斯噪声**：对像素值添加连续随机扰动。
- **椒盐噪声**：随机将部分像素替换为黑色或白色。

对于图像去噪模型，可以分别使用高斯噪声、椒盐噪声以及混合噪声进行训练，并比较它们在不同测试噪声下的去噪效果。

如果主要目的是减少彩色噪点，也可以保留高斯噪声，但让 RGB 三个通道共享同一份噪声，从而生成灰度式扰动，而不必完全替换为椒盐噪声。
